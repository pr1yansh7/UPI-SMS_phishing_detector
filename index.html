How to enable full ML predictions (trained Random Forest)
Right now: Working in heuristic mode — scores URLs using 38 weighted rules directly in your browser. No setup needed.

Easiest: double-click run.bat (Windows) or run ./run.sh (Mac/Linux) — it installs, trains, starts the backend and opens this page.

Or manually (one-time, ~5 min):
1. Open a terminal in the project folder

3. Train: python trainer.py --raw data/sample_urls.csv
4. Start API: python api.py  ← keep this terminal open
5. Refresh this page — status bar turns green automatically
